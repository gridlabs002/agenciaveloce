# Site Veloce

Site preparado a partir do HTML fornecido pelo usuário em 2026-10-06.

Execute `npm start` e abra http://localhost:3000. O servidor usa a variável `PORT`; `/health` permite verificar disponibilidade.

Publicação: projeto Railway `9b077954-6960-45c1-8105-0d3dccf79b9c`, ambiente production, serviço veloce-site.

As rotas de blog e materiais não foram fornecidas. Retornam 404 com mensagem de conteúdo em preparação; o formulário de material só abre quando o destino existe. O quiz conserva o webhook fornecido. O recebimento real no webhook não foi testado com dados de pessoas. Métricas, depoimentos e marcas são conteúdo do HTML recebido, sem validação independente.
